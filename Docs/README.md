# Pakettipörinä – dokumentaatio

Päivitetty 24.11.2026. Pääasiallinen esittely ja kuvat ovat repon juuren [README.md](../README.md):ssä.

Pakettipörinä on lapsiystävällinen 3D-mobiilipeli (Android, Unity 2022.3 URP): rakenna auto, valitse paketti ja rata, aja maaliin (1–3 tähteä), pese ja korjaa. Tähdet avaavat sisältöä, kolikoilla ostetaan tarroja.

## Tila (24.11.2026)
Pelattava: halli (3 vaihetta), 5 rataa (Satama, Puisto, Huvipuisto, Maatila, perusrata), pesu ja korjaus, tähti- ja kolikkotalous, 36 tarraa, 32 osaa, 10 pakettia, tallennus, asetukset, äänet. Kylä myöhemmin. Laitetesti, lokalisointi, vanhempainportti ja lisenssikirjaukset avoinna.
