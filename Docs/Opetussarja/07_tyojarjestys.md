# Työjärjestys opetussarjan materiaalien luomiseen

## Vaihe 0: pohjatyö (ei vielä kirjoittamista)
1. Täytä lisenssi-inventaario (05). Päätä mitä on myytävää.
2. Päätä repo-jako ja luo tyhjä opetusrepo. Pushaa nykyinen työ.
3. Korjaa pelin sanasto (pisteet vs ajotähdet). Lisää testit (RateRun).
4. Vastaa avoimiin kysymyksiin (02): kieli, alusta, kohderyhmä, Unity-versio.

## Vaihe 1: osat 1-3 (validointi)
Jokaiselle: kirjoita yksinkertaistettu opetuskoodi puhtaaseen projektiin -> testaa -> kuvakaappaus/GIF -> artikkeli osamallilla -> alku- ja loppuprojekti.
Julkaise, mittaa (lukijat, osaan 3 asti jatkaneet, kysely FBX/työkalut/molemmat).

## Vaihe 2: päätös
Jatka koko sarja / keskity työkaluihin / lopeta, mittausten mukaan.

## Vaihe 3: osat 4-21, jaksoittain
Perusta (4-6) -> Peli (7-15) -> Julkaisu (16-20) -> Oma peli (21). Maksullisen paketin kokoaminen rinnalla (FBX, työkalujen yleistys, spritet, äänet, scenet).
